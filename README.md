# auth
Семинарский сервис для модуля Backend-разработка

Локальное окружение (Python 3.12):

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
```

Запуск сервиса на http://localhost:8003:

```sh
python main.py
```

Запуск тестов:

```sh
python -m pytest
```

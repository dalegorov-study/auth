## **Цель этого ДЗ**

Научиться выполнять запросы к внешним сервисам конкурентно с помощью asyncio: запускать их одновременно, ставить таймауты, ограничивать число одновременных запросов и находить код, который блокирует event loop. Закрепить работу с потоками на примере потокобезопасного кеша.

## **Сетап**

Задание состоит из трёх задач. Они лежат в папке `homework`:

* `01_async_prices` — сравнение цен в магазинах (asyncio: `gather`, `wait_for`, `Semaphore`)
* `02_find_blocking` — поиск и исправление блокировки event loop
* `03_thread_safe_lru` — потокобезопасный LRU-кеш (`threading`)
* `04_mini_event_loop` — бонусная задача: свой мини-event loop

В каждой папке есть условие (`README.md`), заготовка решения и тесты. Менять можно только файл с заготовкой, тесты трогать нельзя.

Нужен Python 3.12 или новее.

* 10 баллов — тест `test_limited` проходит.

### **Бонус 2 (сложное). Свой мини-event loop — до 30 баллов**

На лекции мы разбирали event loop на генераторах: задачи засыпают через `yield from sleep(...)`, а планировщик по очереди продвигает готовые задачи и будит спящие. Нужно добавить в него ожидание результата другой задачи — аналог `result = await task` в asyncio.

Условие, заготовка и тесты — в папке `04_mini_event_loop`.

**Что сделать:**

* Добавьте системный вызов `AwaitTask(tid)` и helper `await_task(tid)`.
* Научите планировщик хранить результаты завершённых задач и будить всех, кто их ждёт.
* Ждущая задача не должна выполняться, пока результат не готов (без опроса в цикле).
* Если задача уже завершилась, `await_task` возвращает результат сразу.
* Если ждать некого и некому разбудить — бросьте `RuntimeError` с текстом про deadlock.

**Критерии:**

* 0 баллов — `AwaitTask` и `await_task` не реализованы, тесты не запускаются.
* 10 баллов — работает базовый сценарий: одна задача ждёт другую и получает результат.
* 20 баллов — задачи выполняются одновременно (время ≈ самой долгой), работают уже завершённые задачи, несколько ждущих одну задачу и цепочки ожиданий.
* 30 баллов — все тесты проходят, включая обнаружение дедлока.

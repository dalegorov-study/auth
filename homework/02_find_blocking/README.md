# Задача 2. Найди блокировку

В `notifications.py` — рассылка писем пользователям. Функция `notify_all`
запускает отправку всех писем одновременно через `asyncio.gather`, каждое
письмо отправляется ~0.5 с. Значит, 4 письма должны уйти примерно за 0.5 с.

Но если запустить:

```bash
python3 notifications.py
```

рассылка занимает ~2 с, а по логам видно, что письма уходят строго по одному.

**Что сделать:**

1. Найти строку, из-за которой корутины не выполняются одновременно.
2. Исправить её так, чтобы 4 письма уходили примерно за 0.5 с.
3. Ответить в комментарии рядом с исправлением: почему исходный код
   работал последовательно, хотя стоял `asyncio.gather`?

Менять можно только `notifications.py`. Логику писем и тексты не трогайте.

## Как проверить

Из папки задачи:

```bash
python3 notifications.py   # должно быть ~0.5 с
pytest -v
```

# Задача 1. Сравнение цен в магазинах

Сервис сравнения цен опрашивает API нескольких магазинов. Запрос к API
имитирует функция `fetch_price(shop)` в `prices.py`: она «ждёт ответа»
через `asyncio.sleep` и возвращает цену. Её менять нельзя.

| Магазин | Цена | Время ответа |
| --- | --- | --- |
| `ozon` | 990 | 0.3 с |
| `wb` | 950 | 0.2 с |
| `yandex` | 1100 | 0.4 с |
| `slow_shop` | 900 | 5 с |

Нужно дописать функции в `prices.py`.

**1.1. `get_prices_sequential(shops)`** — запросить цены по очереди.
Для `["ozon", "wb", "yandex"]` вернуть `[990, 950, 1100]` примерно за 0.9 с
(сумма задержек).

**1.2. `get_prices_concurrent(shops)`** — то же самое, но все запросы
одновременно через `asyncio.gather`. Результат тот же, порядок цен совпадает
с порядком магазинов, время — примерно 0.4 с (самый долгий ответ).

**1.3. `get_price_or_none(shop, timeout)` и `get_prices_with_timeout(shops, timeout)`** —
если магазин не ответил за `timeout` секунд, вместо цены вернуть `None`.
Для `["ozon", "wb", "yandex", "slow_shop"]` и `timeout=1.0` — вернуть
`[990, 950, 1100, None]` примерно за 1 с, а не за 5.

**1.4 (дополнительная). `get_prices_limited(shops, limit)`** — запросить
цены одновременно, но так, чтобы в любой момент шло не больше `limit`
запросов. Так делают, чтобы не превысить лимиты внешнего API.
Используйте `asyncio.Semaphore`.

## Как проверить

Из папки задачи:

```bash
python3 prices.py   # посмотреть время своих решений
pytest -v           # прогнать тесты
```

Пока функция не написана, её тесты падают с `NotImplementedError` — это нормально.

## Подсказки

- `async def` возвращает корутину, её нужно `await`-ить — иначе ничего не выполнится.
- `asyncio.gather(*coros)` принимает корутины через `*` и возвращает список результатов в том же порядке.
- `asyncio.wait_for(coro, timeout=...)` при превышении бросает `TimeoutError`.
- Семафор: `sem = asyncio.Semaphore(3)`, а внутри задачи `async with sem: ...`.

# Домашнее задание: asyncio и потоки

| Задача | Папка | Тип |
| --- | --- | --- |
| 1. Сравнение цен в магазинах (1.1–1.3) | `01_async_prices/` | Обязательная |
| 1.4. Ограничение числа одновременных запросов | `01_async_prices/` | Дополнительная |
| 2. Найди блокировку | `02_find_blocking/` | Обязательная |
| 3. Потокобезопасный LRU-кеш | `03_thread_safe_lru/` | Обязательная |

В каждой папке: условие (`README.md`), заготовка решения и тесты (`test_*.py`).
Меняйте только файл с заготовкой, тесты не трогайте.

## Подготовка

Нужен Python 3.12 или новее.

```bash
pip install -r requirements.txt
```

## Как проверить

Из папки задачи:

```bash
pytest -v
```

Задача считается решённой, когда все её тесты зелёные (для задачи 1 без
дополнительной части — все тесты, кроме `test_limited`).
